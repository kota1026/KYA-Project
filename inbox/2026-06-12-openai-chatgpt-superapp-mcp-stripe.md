# OpenAI が ChatGPT をスーパーアプリ化——MCP でアプリ統合・決済は Stripe に集約

## 要約
OpenAI は ChatGPT を単一インターフェースに集約するスーパーアプリ戦略を加速。アプリ統合レイヤーに MCP(Model Context Protocol)、決済処理に Stripe を採用し、商取引の完全自律化を目指す。なお 3 月に廃止した「Instant Checkout」の反省を踏まえ、今回は加盟店主導のアプリ連携モデルに転換。Visa との提携(6/10 発表)でトークン化カード決済も追加し、175M 加盟店網へのアクセスを確保した。

## なぜ KYA に関係あるか
OpenAI が MCP+Stripe+Visa を三位一体で構築する決済スタックは、KYA の実装例として最大規模の参照事例になる。エージェントの認証・認可フローを Stripe/Visa のインフラに乗せる設計は、Track A のビジネスモデル分析と Track B の規制論点(誰がエージェントを保証するか)に直接影響する。

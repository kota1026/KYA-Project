# Fiserv、Mastercard Agent Pay Acceptance Framework をマーチャント決済基盤に統合

## 要約
Fiserv が Mastercard の Agent Pay Acceptance Framework を自社マーチャント受付インフラに統合すると発表。AI エージェントが開始した購買を既存のカードネットワークのレールで認証・トークン化・決済処理できるようにする。Fiserv は米国最大級の PoS／決済処理業者であり、同社への統合は AP4M の普及速度を大幅に加速させる。これにより Mastercard AP4M は「プロトコル」から「稼働中インフラ」に格上げされる。x402 などのオープンプロトコルとの競争においてクローズドなカードレール優位性が顕在化した事例。

## なぜ KYA に関係あるか
Fiserv + Mastercard の統合が実現すれば、KYA ソリューションがターゲットにするマーチャント層が既存の Fiserv エコシステムに取り込まれるリスクがある。Track D のビジネスモデル分析において「大手 PSP 統合 vs オープンプロトコル」の二択が具体化。独立 KYA の事業機会は PSP 非対応領域（ロングテール API エコノミー等）に絞られる可能性。

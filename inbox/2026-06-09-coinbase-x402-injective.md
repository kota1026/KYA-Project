# Coinbase x402、Injective Network に展開——AI エージェントのリアルタイム API 課金を実現

## 要約
Coinbase の x402 プロトコルが2026年6月9日、Injective Network に展開された。x402 は AI エージェントがアカウント作成やサブスクリプションなしでリアルタイムに API 料金を支払える仕組みで、Injective の高頻度低レイテンシ金融インフラと組み合わせることで、自律エージェントの機械ネイティブ決済を強化する。x402 は既に Base・Solana を主要チェーンとしているが、Injective 追加により DeFi 特化チェーンへの展開が進む形。x402 は直近30日で7,500万件超のトランザクションを処理（推定）。

## なぜ KYA に関係あるか
x402 のマルチチェーン展開は、エージェント決済の決済レイヤーとしての地位を固める動きで、Track A（Coinbase/x402 競合プロファイル）の更新情報。KYA の「どのチェーン・決済レールを前提とするか」の設計判断にも影響する。

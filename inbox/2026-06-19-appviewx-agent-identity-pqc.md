# AppViewX、AI エージェント向け PKI 基盤 Agent Identity Security を Private Preview 公開

## 要約
AppViewX が 2026 年 6 月 16 日、AIエージェントの発見・ガバナンス・セキュリティ・監視を一元管理する「Agent Identity Security」を発表。PKI 基盤と AI エージェントガバナンスを統合し、PQC(耐量子暗号)移行にも対応する設計。CISO に対し「機械 ID とエージェント ID の単一コントロールプレーン」を提供。Private Preview として Identiverse 2026 でデモ公開。

## なぜ KYA に関係あるか
KYA の技術スタック候補として PKI + DID ハイブリッドアプローチを具体化した商用製品。既存 PKI インフラを持つ金融機関にとって現実的な導入経路。Track C の技術動向と Track A の競合/補完プレーヤー分析に追加。

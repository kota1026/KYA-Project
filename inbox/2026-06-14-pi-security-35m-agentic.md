# Pi Security、エージェント AI セキュリティで $35M 調達（2026-06-10）

## 要約（3-5 文）
Pi Security は2026年6月10日、エージェント型 AI のセキュリティインフラに特化した $35M の資金調達を完了した。エージェントの認証・アクセス制御・異常検知を統合したプラットフォームを展開しており、NHI（Non-Human Identity）管理と競合する領域。同週に Trustap（AI エージェントによる取引管理、$10M）も調達しており、エージェント経済のセキュリティ層への VC 集中が続いている。

## なぜ KYA に関係あるか
Pi Security は KYA の Runtime Controls / Audit 層と直接重なる。既存 inbox の Oasis Security $120M（2026-05-24）と同じ NHI セキュリティ競合群に位置付けられ、Track A の競合マップ更新が必要。エージェント identity/access 市場に特化したスタートアップへの資金流入が継続しているトレンドを示す。

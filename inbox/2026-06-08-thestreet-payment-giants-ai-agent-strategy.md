# なぜ決済大手は AI エージェントに「鍵」を渡すのか

## 要約（3-5 文）
TheStreet が Visa・Mastercard・Stripe・Coinbase の AI エージェント対応戦略を横断分析（2026-06-07 推定）。Visa の Intelligent Commerce は API 経由で identity チェックと支出制御を組み込み、Mastercard の Agent Pay はトークン化とルール設定で対応。Stripe x402 は USDC/Base 経由のエージェント決済パスを提供。各社がそれぞれ独自プロトコル（AP2・MPP・x402）を展開しており、標準化競争が激化している構図を整理。

## なぜ KYA に関係あるか

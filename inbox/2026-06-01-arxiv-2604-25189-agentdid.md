# AgentDID: Trustless Identity Authentication for AI Agents (arXiv 2604.25189)

## 要約
AI エージェントは自律的に起動・移行・他エージェントと通信するため、既存の PKI/OAuth では対応困難。本稿は DID (Decentralized Identifiers) と VC (Verifiable Credentials) を組み合わせ、エージェントが中央管理なしに自己主権型 ID を保持・認証できるアーキテクチャを提案する。ZKP による selective disclosure も取り込み、verifier 間での相関追跡を防ぐ。

## なぜ KYA に関係あるか
KYA の「エージェント ID ≠ モデル ID」問題を DID/VC で解く直接的な先行研究。選択的開示 + プラットフォーム横断認証 = KYA コアコンポーネントの技術実装候補。

# Ripple、XRPL AI Starter Kit を正式公開——x402 + RLUSD で自律決済、Mastercard AP4M に参画

## 要約（3-5 文）
Ripple は2026年6月11日、AI エージェントが人間の介在なしに XRP Ledger 上で自律決済を行うための開発者ツールキット「XRPL AI Starter Kit」を公開した。x402 プロトコル経由で XRP および RLUSD（Ripple USD ステーブルコイン）による API・コンピュート対価支払いが可能になり、決済確定は 3〜5 秒・ガス価格競売なし。クロード統合（XRPL Agent Wallet Skill / XRPL Payment Skill）と XRPL Docs MCP Server を含み、Claude Code・Claude Desktop・Cursor から直接 XRPL にアクセスできる。同日 Mastercard が Ripple を Agent Pay for Machines（AP4M）の 30 社以上のローンチパートナーに指名し、XRPL が AP4M のブロックチェーン決済レイヤーとして位置づけられた。

## なぜ KYA に関係あるか
競合マップ（Track A）において Ripple は決済レール層の有力プレーヤーとして浮上。x402 + RLUSD は Coinbase/Base の x402 実装と直接競合し、決済プロトコルの主導権争いに参加。KYA の文脈では、XRPL 上のエージェントアイデンティティ（ウォレット生成・トランザクション追跡）がどう実装されるかがポイント。Claude 統合は KYA が「デベロッパーツールとして普及」するモデルの実例。

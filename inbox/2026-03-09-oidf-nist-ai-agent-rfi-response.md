# OIDF が NIST「AI エージェント・セキュリティ RFI」に回答：トランザクション・トークンと Workload Identity を推奨

## 要約（3-5 文）
OpenID Foundation（OIDF）の AI Identity Management（AIIM）コミュニティグループが 2026-03-09 の NIST-2025-0035 コメント締切に合わせて公式回答を提出。NIST に対して、トランザクション・トークン・Workload Identity Federation・AI ツールプロトコル向け認証拡張などの既存実用標準を指示するガイダンスの策定を要請。エージェントのなりすまし・過剰権限・監査証跡欠如を主要脅威として列挙。W3C DID/VC・IETF RFC との整合を想定した相互運用可能なフレームワーク設計を提案。

## なぜ KYA に関係あるか
KYA の技術スタック選定に直結する標準動向。OIDF が NIST に推奨するプロトコル群（トランザクション・トークン、Workload Identity Federation）が KYA の認証層の有力実装候補。Track C 標準セクションに追加し、FIDO Alliance・AP2・Verifiable Intent との関係図に組み込むこと。

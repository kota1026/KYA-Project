# Adyen、エージェント商取引向け API スイート「Adyen Agentic」を発表（2026-06-16）

## 要約（3-5 文）
2026-06-16、Adyen は Adyen Agentic を発表—Agentic Feed（カタログ・価格のリアルタイム配信）、Agentic Cart（チェックアウト・税務・フルフィルメント接続）、Agentic Payments（認証・トークン可搬性・リスク管理）の 3 レイヤー構成。既存のコマースシステムを再構築せずに LLM ベースの会話型プラットフォームから販売可能にする設計。当初は米国の大企業向け限定提供で、パートナーに American Express・Mastercard・Salesforce・Visa が参加。発表後に ADYEY 株が 4% 超上昇。

## なぜ KYA に関係あるか
Adyen Agentic の Agentic Payments レイヤーは「認証・トークン可搬性・リスク管理」を担うと明記しており、KYA の「エージェントが誰か」を確認する機能と直接競合または補完する領域。大型既存決済プロセッサ（処理量 No.2 級）がエージェント認証インフラに参入したことは Track A 競合地図の更新を要する。

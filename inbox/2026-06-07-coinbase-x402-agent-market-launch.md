# Coinbase x402、AI エージェント向け App Store「Agent.market」を公開

## 要約（3-5 文）
x402 Foundation が 2026-04-21 に Agent.market（別称 Agentic.market）を公開。API キー不要でステーブルコイン払いによりエージェントがサービスを発見・購入できる 7 カテゴリ（Reasoning / Data / Media / Search / Social / Infrastructure / Trading）のマーケットプレイス。発表時点で約 69,000 のアクティブ AI エージェントが 1.65 億件、5,000 万ドル超の累計取引を処理。バッカーは Cloudflare・Stripe・AWS・Google・Visa・Circle・Solana Foundation など 20 社超。

## なぜ KYA に関係あるか
エージェントが「匿名」で購買できるマーケットプレイスの成立は、KYA（Who is this agent? Is it authorized?）の問いを実運用で突きつける事例。Track A のプロトコル競争地図に x402 エコシステムの拡張として記録。Track D のビジネスモデル検討でも「マーケットプレイス手数料型」として参照価値あり。

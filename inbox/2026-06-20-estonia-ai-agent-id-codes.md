# エストニア、AI エージェントへの「AI ID コード」付与計画を発表

## 要約
エストニア政府が AI エージェントに固有の「AI ID コード」を付与する計画を発表した（詳細はBiometric Update 2026年6月報道、推定）。識別目的およびエージェントの活動範囲を制限することが目的。EU 加盟国として初の政府主導エージェント ID 制度であり、EU AI Act の施行(2026年8月)に先行する形。法的人格・責任帰属・スコープ制限の設計について新たな問いを提起している。

## なぜ KYA に関係あるか
「エージェントに政府 ID を発行する」という実装は KYA の国家レベル応用例。EU AI Act 対応として他加盟国への波及可能性がある。ノンカストディ型 KYA の文脈では、エージェントに直接 ID を与えるか、人間 → エージェントの委任チェーンで管理するかの設計論点が深まる。Track B EU 節の重要事例。(推定)

# Biometric Update：アイデンティティ業界、エージェンティック・コマースのトラストギャップ解消に動く

## 要約（3-5 文）
Mastercard Agent Pay、Prove Verified Agent 等がエージェンティック・コマースのトラスト層構築を本格化していることを Biometric Update が 2026-06 にまとめた。Mastercard・Worldline・ING が欧州初の完全リージョナル・オーケストレーション型エンド to エンドエージェント取引をライブ実施、passkey 認証でユーザー同一性を担保した。Prove は電話番号・国民 ID・決済認証情報をバインドした暗号証明付き「Verified Agent」を提供し、単一の監査可能な取引ユニットを実現。IMF は KYC・MFA がヒューマン前提設計であることを問題視する論文を発表（推定：同時期公開）。

## なぜ KYA に関係あるか
KYA の核心「エージェントを誰が責任を持って授権したか」を証明する Verifiable Intent と Prove Verified Agent は、Track A の競合プロファイルとして追加すべきプレイヤー。ライブ取引事例は Track B（EU/UK の規制整合性証拠）にも流用可能。

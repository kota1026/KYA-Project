# Akamai が KYA プロトコルをエッジで展開 — Skyfire・Experian・Visa と共同開発

## 要約
Akamai は2026年6月15日、Agentic Security Framework を発表。KYA プロトコルを Skyfire・Experian と共同開発し、エージェントが身元・来歴・意図を宣言する標準化スキームを提供。Visa Trusted Agent Protocol と統合し取引レベルの信頼を確立。Auth0・Ping Identity も参加。6 本柱: 検証済み ID・ユーザー中心認証・適応型信頼分析・エッジ強制・収益化・可視性。

## なぜ KYA に関係あるか
Skyfire との KYA 共同開発は Track A の競合マッピングに直結。Visa/Auth0 連合は KYA のエンタープライズ標準化を推進し、Track B(規制)・Track C(技術)両方に影響。CDN 大手の参入で KYA が「インフラ層」に組み込まれる動きが鮮明。

# Tools for Humanity、World ID を企業向け Proof-of-Humanity に転換 — Zoom・Okta 等と連携

## 要約
Sam Altman 共同創業の Tools for Humanity が2026年6月、World ID をエンタープライズ認証基盤として再定義。iris スキャン由来の proof-of-humanity を Zoom・Okta・DocuSign・Shopify・VanEck 等に展開。deepfake 防止・bot 対策・継続的ヒューマン検証を企業向けに提供。マルチキー・アカウントアーキテクチャで IT 部門のベンダー独立性要件に対応。ユーザー向けは無償、アプリ側課金モデル。

## なぜ KYA に関係あるか
ヒューマンバインディング(エージェント背後の実在人間証明)は KYA の必須要件。World ID の企業展開が進むと非カストディ型 Wallet の KYC 代替として台頭する可能性。Track A 競合マップに human-binding 提供者として追加すべき。

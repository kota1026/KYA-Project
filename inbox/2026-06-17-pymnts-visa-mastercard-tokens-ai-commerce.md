# PYMNTS: Visa と Mastercard、AI コマース制覇の鍵に「トークン」を据える

## 要約
Visa と Mastercard が、エージェント主導コマースの戦略的要衝として「トークンサービスプロバイダー(TSP)層」の制御を争っている構図を PYMNTS が分析。Visa は OpenAI と連携し、特定エージェント・特定ユースケースに bound されたネットワークトークンを発行。Mastercard の Agentic Token は特定エージェント × 特定マーチャントスコープ × 同意ポリシーをバインドし、生カード番号を露出せずに決済を完結させる。戦略的賞品は「アイデンティティ + 認可 + 決済情報が収束する TSP 層の支配権」と整理。

## なぜ KYA に関係あるか
Visa/Mastercard が TSP 層にアイデンティティ情報を格納するモデルは、KYA ソリューション提供者との競合・協調関係を決定する。両社が closed-loop でエージェント ID を管理するか、open standard に乗るかで市場構造が変わる。Track A 競合マップの "既存決済ネットワーク" セルに追加必須。

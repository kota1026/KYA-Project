# Casper Network、WebAssembly ネイティブ L1 として初の x402 本番稼働を発表・$150K Buildathon 開始

## 要約（3-5 文）
Casper Network は 2026-06-04 に AI ツールキットをメインネットで正式公開し、WebAssembly ネイティブ L1 として初めて x402 HTTP マイクロペイメントを本番稼働させた。スタックは x402（HTTP ベースのマイクロペイメント）・MCP（オンチェーン直接操作）・Odra Framework（AI 駆動スマートコントラクト開発）で構成される。$150,000 の Agentic Buildathon を並行開始し、参加チームには x402 Facilitator 手数料を無償提供。Istanbul Blockchain Week（6/2）でのハンズオンワークショップで参加者がライブでエージェントを構築した。

## なぜ KYA に関係あるか
x402 の採用チェーンが Arbitrum/Base 圏外に拡大していることを示す事例。Wasm ネイティブ環境でのエージェント決済が技術的に成立することは、Track C の実装オプション幅を広げる。Buildathon の成果物が KYA 参照実装になり得る。

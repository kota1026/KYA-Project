# x402 の「Approval Gap」問題——ユーザー確認摩擦がマイクロペイメント経済性を脅かす

## 要約（3-5 文）
x402 取引量が 2025 年 11 月の月間 515 万ドルから 2026 年 5 月には 119 万ドル（▲77%）に落ち込んでいる一方、取引件数は同期間比で 289 万件（+12.5x from Feb trough）と回復傾向。平均取引額は約 0.52 ドルで API 課金規模。毎回の手動承認（5〜15 秒）を月間 289 万件に掛けると 4,000〜12,000 時間の「承認摩擦」が発生し、0.01 ドル API 呼び出しに対しては経済的に成立しないと指摘。

## なぜ KYA に関係あるか
エージェントへの事前の権限委任（=KYA のスコープ設定）が解決策として浮上している。AP2（Google/FIDO）の「Mandate（委任状）」形式が代替手段として言及。KYA における「事前認可 vs 都度承認」のトレードオフを実データで示す事例として Track A / Track D の両方に参照価値。

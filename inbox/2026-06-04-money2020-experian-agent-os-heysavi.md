# Money20/20 Europe Day 1: Experian Agent OS・Hey Savi agentic commerce など新発表

## 要約（3-5文）
Money20/20 Europe 2026 初日、Experian が「Agent Operating System」（Experian Ascend Platform内の信頼できる agentic AI 層）を発表、ServiceNow が初パートナーとして統合。英国スタートアップ Hey Savi は PayPal 連携の UK 初 agentic commerce 体験をローンチ、写真・スクリーンショット・テキスト検索から1万ブランド以上の結果を取得してアプリ内購入を完結させる。イベントの4大テーマは「AI and the Agentic Age」「The Great Rebundling」「Money Stack Rewired」「Regulation in the Fast Lane」。

## なぜ KYA に関係あるか
Experian の Agent OS は「コントロール・監査性・人間監視」を KPI として掲げており、Track A の競合マップ（既存 KYC/ID ベンダーの agentic 参入）に追加すべき事例。Hey Savi の PayPal 統合はアジェンティック・コマースの UK 消費者向け最前線事例。どちらも KYA インフラの直接競合ではなく隣接プレイヤー。

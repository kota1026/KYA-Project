# Visa Payments Forum 2026: OpenAI 戦略提携・ステーブルコイン $7B・トークン預金を発表（2026-06-13）

## 要約（3-5 文）
Visa は2026年6月13日の Visa Payments Forum で、OpenAI との戦略提携によりエージェント決済内での Visa 認証を有効化すると発表した。ステーブルコイン決済の年率換算は2026年3月時点で約 $70 億ドルに到達、地域・チェーンを拡大予定。銀行が伝統的預金をプログラマブルな「常時稼働デジタルマネー」（トークン預金）に変換できる技術層も展開する。大規模言語モデル向けに不正取引を検知しながら承認率を向上させる「Large Transaction Model」も合わせて発表。

## なぜ KYA に関係あるか
Mastercard Agent Pay（6/10）に続き Visa も同週にエージェント商取引インフラを正式化した。Visa の「Agentic Directory」（既存 inbox 2026-06-10 ファイル）と今回の OpenAI 連携が組み合わさり、Track A の「大型カードネットワーク vs 新興プロトコル」構図の比較分析が必要。ステーブルコイン $70 億 run rate は Track B GENIUS Act 準拠との交差点として Track D ビジネスモデルにも影響。

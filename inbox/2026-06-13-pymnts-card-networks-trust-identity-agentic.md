# PYMNTS「Card Networks Use Trust and Identity to Build Agentic Commerce」——Visa vs Mastercard の比較分析

## 要約
Visa と Mastercard がエージェンティック・コマースの信頼基盤として「エージェント ID 検証」に共同で注力していることをPYMNTS が分析。Visa は Trusted Agent Protocol(TAP)でエージェント ID とふるまいをチェックアウト前に検証しリスクの高い取引では人間承認を維持。Mastercard は AP4M の Verifiable Intent(改ざん防止の事前ユーザー承認記録)とブロックチェーン上の権限管理で対抗。FIDO Alliance・EMVCo の業界標準化活動にも両社が参加しており「誰がエージェントに権限を付与したか」の証明が競争軸に。識別(ID)・承認(Authorization)・監査証跡(Audit Trail)の三要素が決済ネットワーク組み込みで実装されつつある。

## なぜ KYA に関係あるか
KYA プロジェクトが想定する「エージェント ID + 委任検証 + 監査証跡」の三要素が Visa・Mastercard の両方で実装方針として確定した。独立系 KYA ソリューションのポジショニングを「ネットワーク非依存」で差別化する根拠と競合圧力を同時に示す重要資料。Track A・B 双方に横断記録が必要。

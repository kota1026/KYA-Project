# Gopher Security: Post-Quantum AI Infrastructure Security — MCP 向け 2026 ガイド

## 要約
MCP サーバー・エージェント通信を PQC で保護するための実装ガイド。可視化→分類→TLS 強化→クリプトアジリティの 4 フェーズ。"Harvest Now, Decrypt Later" 攻撃を MCP 環境での主要脅威と位置づけ。ML-KEM / ML-DSA (FIPS 203/204/205) をベースラインとして推奨。

## なぜ KYA に関係あるか
KYA がエージェント認証インフラとして MCP 上に構築される場合、PQC 対応は将来要件。QSB 温存戦略の技術的裏付けとして参照価値あり。

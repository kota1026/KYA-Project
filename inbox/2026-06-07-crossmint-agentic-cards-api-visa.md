# Crossmint、Visa Intelligent Commerce + Basis Theory を用いた Agentic Cards API を公開

## 要約（3-5 文）
Crossmint が 2026-06-02 に Agentic Cards API を正式リリース。米国発行 Visa クレジット・デビットカードを AI エージェントが利用できる仕組みを提供し、カード番号・CVC を非公開のままトークン化して決済を実行する。PCI Level 1 / SOC 2 認定の Basis Theory をクレデンシャル層に採用し、支出上限でエージェントの行動を制限。同社自社ウォレット lobster.cash にすでに統合済み（Claude Code・OpenClaw・Hermes・Zo Computer 対応）。

## なぜ KYA に関係あるか
Crossmint はエージェント向けウォレット・決済インフラの主要競合（Track A）。Visa Intelligent Commerce Connect との連携は既存カード基盤をエージェント経済に接続する重要なブリッジ。エージェントへの権限委任（credential delegation）と支出制限がどう設計されるかは KYA のユースケース定義に直結する（Track A プロファイル + Track B 規制適合）。

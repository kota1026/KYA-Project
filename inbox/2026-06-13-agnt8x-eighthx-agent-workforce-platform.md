# agnt8x (EightX Labs)、AIエージェント採用・労働力管理プラットフォームを公開——「Passport」と EAM 仕様を提供

## 要約
シンガポール法人 EightX Labs が agnt8x.ai を2026年6月3日に公開。企業が人材採用と同じ感覚でエージェントを「検索・採用・オンボード・管理・オーケストレーション」できるプラットフォーム。全エージェントに一つの「Passport」（ID + 監査証跡）と統一契約を提供し、全主要 LLM プロバイダをカバー。オープンソース仕様「EightX Agent Manifest (EAM) v0.1」を Apache 2.0 で公開し移植性を確保。FIND（エージェント版求人ボード）と FORGE（社内エージェント管理）の二層構造。エージェント標準規格(WIMSE/AP2等)との整合を表明。

## なぜ KYA に関係あるか
「エージェントに Passport を発行する」アプローチが KYA の核心と完全に一致する新興競合。B2B 向け管理 UI・マーケットプレイスという切り口は KYA プロジェクトが対象とする企業ユースケースと重なる。EAM の仕様内容と WIMSE 整合性の確認が必要。アジア（SG発）のプレイヤーであり地理的カバレッジも注目点。

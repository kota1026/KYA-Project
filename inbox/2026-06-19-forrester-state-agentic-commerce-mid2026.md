# Forrester: Mid-2026 時点でエージェント自律決済は依然レア、会話型 UI が主流

## 要約
Forrester 分析。2026 年中盤時点でほとんどの「エージェティック」体験はまだ会話型(商品発見・レコメンド)にとどまり、最終決済は人間が実行するケースが大半。B2B ユースケースは増加傾向だが初期段階。OpenAI が ChatGPT のインスタントチェックアウト機能を撤廃したことを「agentic commerce の限界」の象徴として言及。真の自律性を持つエージェント決済は少数派。

## なぜ KYA に関係あるか
エージェント自律決済の普及時期はまだ不確実で市場形成段階。KYA を「決済信頼インフラ」として早期ポジション取りするタイミングの妥当性を裏付ける。Track D の時間軸シナリオに反映。

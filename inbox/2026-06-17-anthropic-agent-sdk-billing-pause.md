# Anthropic、Agent SDK 課金分離を一時停止 — OpenAI との価格競争が背景か

## 要約
Anthropic は2026年5月、Agent SDK・claude-p・Claude Code GitHub Actions 等を月次クレジット別建て化すると予告(Pro $20、Max 5x $100、Max 20x $200)。しかし2026年6月15日に一時停止を発表。OpenAI のトークン価格引き下げ検討や中国 AI モデルによる最大9倍のコスト差が圧力として報道されている(推定)。「Nothing changes for now」とユーザーに通知。

## なぜ KYA に関係あるか
エージェント SDK のコスト構造変動はエージェント開発者の経済性に影響。KYA 普及コストの前提条件を形成する。Track D の LLM プロバイダーコスト競争分析に材料。投資推奨ではない。

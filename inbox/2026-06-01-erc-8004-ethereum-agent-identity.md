# ERC-8004: Ethereum オンチェーン AI エージェント ID レジストリ (メインネット稼働)

## 要約
ERC-8004 は AI エージェントに ERC-721 ベースのオンチェーン ID を付与する Ethereum 標準。Identity Registry・Reputation Registry・Validation Registry の 3 コンポーネントで構成。2026/1/29 にメインネット稼働。L2 では 1 エージェントあたり登録コスト $1 未満。MetaMask / Ethereum Foundation / Google / Coinbase が共同提案。

## なぜ KYA に関係あるか
KYA インフラの「パブリックチェーン上のエージェント ID 層」として直接参照できる実装。ノンカストディ型との親和性が高く、競合他社（Skyfire 等）との技術差別化軸になりうる。

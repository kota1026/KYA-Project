# Travala、AI エージェント向け旅行予約プロトコル「Travel MCP」を Base x402 で公開

## 要約
Travala が 220 万件超のホテルを AI エージェントが検索・予約・決済できる Travel MCP を発表。Base 上で x402 規格のガスレス USDC 決済に対応し、ERC-7715 セッションキーで最終署名権をユーザー側に保持しつつ自律実行を実現。ERC-8004 でエージェントパフォーマンスの機械検証可能なトラスト層を搭載。Claude との統合で単一チャットスレッド内での完全旅行手配が可能。開発者向けに cbBTC 10% リベートを提供。

## なぜ KYA に関係あるか
x402 初の大規模リアルワールド垂直統合事例。ERC-8004（agent identity / reputation）を決済フローに組み込んだ設計は KYA の参照実装候補。Track A 競合と Track C 技術の両方に即反映すべき最新事例。

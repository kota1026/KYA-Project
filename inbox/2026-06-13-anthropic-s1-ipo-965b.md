# Anthropic が IPO 向け S-1 を SEC に機密提出——時価総額 $965B、ARR $47B

## 要約
Anthropic が2026年6月1日、米 SEC に Form S-1 を機密提出。5月末に完了した $65B の Series H 調達で評価額が $965B に到達しており、IPO では $1T 超での上場が見込まれる。2026年5月の収益実行レートは約 $47B（前年比約5倍成長）。Claude は Amazon Bedrock と主要エンタープライズワークフローに深く組み込まれ、エージェント＋コーディング分野での差別化を継続。上場タイミングは2026年10月を目標とする見通し（推定）。

## なぜ KYA に関係あるか
Claude は KYA プロジェクトのリサーチ基盤として使用中。Anthropic の IPO・財務安定化はツール継続利用の前提条件。また Anthropic のエージェント用途（Bedrock Agent、Claude Code）の拡大は Track C の「基盤モデルがエージェント認証補助を担う」シナリオの現実性を高める。定理証明・コード生成精度の向上が KYC 自動化代替案にも影響。

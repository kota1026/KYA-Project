# Ping Identity、AI エージェントの Runtime Identity を AWS・Google Cloud・Cloudflare に拡張

## 要約
Ping Identity は 2026 年 6 月 16 日、Agent IAM Core / Agent Gateway / Agent Detection の 3 コンポーネントからなる「Runtime Identity」を AWS・Google Cloud・Cloudflare エッジに統合拡張すると発表した。MCP トラフィックへのスコープ済みクレデンシャル付与、ZT ポリシーのエッジ適用、継続的エージェント行動監視が主機能。2026 年 3 月 24 日の GA 以降の最初の大型統合アップデート。

## なぜ KYA に関係あるか
エージェントが cloud + edge を横断して動作する時代に、認証(誰か)と認可(何ができるか)を runtime で連続的に執行するアーキテクチャの参照実装。KYA 技術スタックの C 面(実装パターン)を補強する。競合 Track A では Akamai・Fastly・Skyfire も同様の edge-KYA を展開しており、産業標準が固まりつつある。

# Paytm Q4 FY26 決算：アジェンティック UI でファネル転換率が 7〜8 倍

## 要約（3-5 文）
Paytm CEO Vijay Shekhar Sharma が Q4 FY26 決算説明会（2026-05-31）で、旅行チケット予約アプリ Paytm Checkin のアジェンティック・チャット UI でのファネル転換率が通常 UI 比 7〜8 倍に達すると発言。「新規投資は AI のみ」方針を明言し、ウェルステック・旅行・決済で自律エージェント UI の拡張を優先。インドの UPI 決済基盤を活用しつつ、エージェントが代理で購買・予約を行う使用例で実証データを取得。決済が同社総収益の 55%、フィンテックが 30% を占める構造のため、アジェンティック導線の転換率改善は業績に直結。

## なぜ KYA に関係あるか
アジェンティック決済の転換率改善（7〜8X）という実測データは Track D のビジネスモデル検証に直接使える。インド市場での AI エージェント代理購買は KYA の主要ユースケースであり、ノンカストディ型 KYA の新興市場適用範囲の検討材料になる。

# Visa「Intelligent Commerce Connect」が 6 月 GA 予定 — MPP / TAP / ACP / UCP を単一統合で対応

## 要約
Visa が 4/8 に発表した Intelligent Commerce Connect（ICC）は 6 月の一般提供を予定。TAP・MPP・ACP・UCP を含む主要エージェント決済プロトコルに対応し、Visa / 非 Visa カード双方を単一 API で統合するプロトコル中立ハブ。パイロットパートナーは AWS・Aldar・Highnote 等。Crossmint が ICC + Basis Theory で Agentic Cards API を既に提供開始。

## なぜ KYA に関係あるか
Visa が「プロトコル中立のエージェント決済ハブ」を確立する。KYA はその上位のアイデンティティレイヤーとして各プロトコルの入口に位置付けられる可能性があり、Visa との協調設計が KYA の市場価値を大きく左右する。

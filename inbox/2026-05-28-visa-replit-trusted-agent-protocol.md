# Visa、Replit に投資 ——「Trusted Agent Protocol」でエージェント決済 ID 層を構築

## 要約
Visa が AI コーディングプラットフォーム Replit に非公開額を出資（2026年5月28日）。Replit バリュエーションは3月の Series D（$400M）で $9B。Visa は **Trusted Agent Protocol（TAP）** を提供：エージェントが決済時に「意図・関連顧客情報」を共有し、ペイメントネットワーク側が検証・認可する仕組み。Visa Intelligent Commerce スイートと併せて Replit エージェントに組み込み予定。Visa 社員 1,000 名超が既に Replit を社内利用。

## なぜ KYA に関係あるか
TAP は KYA の中核機能（エージェントが「誰のために・何の意図で動いているか」を決済時に証明）に直接対応する。Visa が独自プロトコルとして定義する動きは、AP2（FIDO）/ x402 等の公開標準と競合しうる。Visa の規模感（グローバルネットワーク）での採用は Track B 規制議論にも波及する可能性が高い。

# Visa × OpenAI、ChatGPT にペイメントネットワーク統合——AI エージェントが自律購買

## 要約(3-5 文)
Visa と OpenAI は2026年6月10日、ChatGPT の AI エージェントが Visa ネットワークを通じてショッピング・決済を自律実行できる統合を発表した。ユーザーは ChatGPT に Visa カードをリンクし、支出上限・利用可能店舗・承認条件を設定；Visa が不正検知・チャージバック・返金を担う。従来の Visa アジェンティック試験は特定小売に限定されていたが、今回は Visa 加盟全店舗に一気に拡大。OpenAI の Codex コーディングエージェントが API サービスを自律購入するユースケースも想定されている(出典: Axios 2026-06-10)。Visa はあわせて Agentic Ready プログラムのグローバル拡大も発表している(出典: investor.visa.com)。

## なぜ KYA に関係あるか
「Visa カードリンク + ユーザー設定ルール」による principal binding が大規模に実装された事例。KYA の "principal binding" アーキテクチャを Visa のトークン・不正検知インフラで代替するモデルであり、Track B（規制上の consent / liability 配分）と Track D（非カストディ KYA vs. Visa モデルの競争）に直接影響。

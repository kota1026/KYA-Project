# Visa、Agentic Directory と Agent Score を発表——AI エージェント向け中央集権型 KYA レジストリを構築

## 要約（3-5 文）
Visa は2026年6月10日の Visa Payments Forum で、AI エージェントと加盟店の双方を「正規参加者」として認証する「Agentic Directory」と、加盟店のエージェント対応度を評価する「Agent Score」を発表した。Agentic Directory は Visa が検証したエージェントと加盟店のリストで、加盟店は信頼できるエージェントを識別でき、エージェント側は正規加盟店との取引確認が可能になる。併せて、不正検知を強化する「Large Transaction Model」（数十億件のトランザクションで学習）、銀行預金をプログラマブルなデジタルマネーに変換する「Tokenized Deposits」、ステーブルコイン決済の地域・ブロックチェーン拡大、ステーブルコイン連動カードも発表（出典: BusinessWire 2026-06-10）。なお既存ファイル（2026-06-10-visa-chatgpt-agentic-commerce.md）は OpenAI/ChatGPT 統合に焦点を当てており、本件は Visa Payments Forum の全体発表（別 URL）を対象とする。

## なぜ KYA に関係あるか
Agentic Directory は「中央集権型 KYA レジストリ」の実装例。Visa ネットワーク参加資格をアイデンティティ基盤とすることで、ノンカストディ型の分散 KYA ソリューションとの差別化軸が明確になる。Track A における Visa の KYA ポジション（中央集権型 vs. 分散型）を更新する必要がある。Track B では、Visa の私的レジストリが将来規制上の"信頼リスト"として引用される可能性の検討が必要（EU eIDAS 2.0 との整合性等）。
